# couralabs.dev hub

Scope: the CouraLabs studio hub (single page, `src/`). Visitor mode: Persuade.
Audience: developers first, future hosted-service users, then people hiring. Job: understand what CouraLabs ships, pick a project, go to its repo or subdomain; hirers go to LinkedIn.
Proof: three real repos (Codeboros pre-release, OpenMixing, OpenHouse) and their READMEs. No stats, stars, testimonials.
Constraints: EN/PT equal, Cloudflare static, dark + light themes (OS default, toggle; dark leads, light is its paper-white inversion), plain professional wording (no game vocabulary), contact = LinkedIn + GitHub org.
Unresolved: final logo; whether hosted versions launch on the project subdomains.

## Direction contract

THESIS: A drafting sheet for software: the page is one visible hairline grid, and each project is a line drawing on it, plotted rather than rendered. Refuses the split hero and the row of three equal cards; replaces the frosted-glass lens world, which is now anti-reference except for the sticky nav.
OWN-WORLD: Black ground (paper white in light), 1px hairline frame running the page with crosshair ticks at intersections, thin outline circles and arcs crossing sections, one bright node dot travelling an orbit, a faint gray light bloom in the hero. Geist Mono as the display and label voice, Doto dot-matrix for small sign-offs and the footer sign, Jost for running copy. White pill buttons paired with a round arrow disc, hairline pill tags, 20px hairline panels, table rows that invert to white on hover.
STORY: The visitor reads a mono headline set across the grid, sweeps the plotter crosshair over the dot grid until it locks onto a project site, watches that project's primitive plot itself into the orbit, opens its sheet, believes it because every line traces to a repo, and leaves via GitHub, a subdomain or LinkedIn.
FIRST VIEWPORT: Framed sheet under a glass nav. Headline in large Geist Mono split across the frame, line one left, line two right, sub copy tucked under line one; right of centre a large hairline orbit with the travelling node dot; dot-matrix corner note top right; sub copy and pill actions under line one; the three projects are sites on the hero's dot grid, found with the plotter crosshair.
FORM: Pinned by the user through five references (Langbase grid and //sections, Nothing dot-matrix and outline circles, a mono-display developer portfolio, a dark DeFi glass set for the light bloom). User chose 2026-10-29: mono display, keep both themes, hairline grid frames. seed: none (pinned by the user; no roll was run for this direction).
Signature interaction: hovering or focusing a project (hero site or project tabs, keys 1-3) plots its primitive by stroke draw-in on the orbit and the row inverts; the project sheet redraws its primitive on selection.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
