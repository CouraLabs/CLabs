The thesis

AI belongs in software you can read, run and own.

  • Useful AI tools are often closed, hosted-only and opaque.
  • Developers want to see the code, self-host it and bring their own model keys.
  • Where hosting is easier, a hosted version should exist as a choice, not a requirement.

A self-hosted autonomous coding agent.

LicenseApache 2.0

StackPython · MCP · ffmpeg
LicenseGPL 3.0
